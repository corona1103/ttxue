# 内容运营后台 Demo

这是一个纯前端静态 Demo，无需安装依赖。

## 打开方式

直接双击 `index.html` 即可打开；如需本地服务预览，可在项目根目录运行：

```bash
python3 -m http.server 8000 --directory ugc平台/product-ops-demo
```

然后访问 <http://localhost:8000>。

## 已覆盖交互

- 合集管理：统计周期筛选、指标随周期变化、作者 ID、查看详情、加微课/取消关联、下架、导出列表
- 微课 Tab 运营：新增精选、排序上下移、合集标题 + ID + 作者信息、剧集播放/下架、下架
- 创作者收入：按作者 + 作者 ID 聚合、作者详情抽屉、趋势图、CSV 导出
- 结算对账：手动导入结算单、重复校验、状态自动查询、作者数、多作者结算详情、CSV 导出

页面数据为内置模拟数据，刷新后恢复初始状态。
