# 创作者运营 PRD：作者跟进与作者作品看板

版本：V1.0  
日期：2026-11-25  
适用 Demo：`ttxue/product-ops-demo`  
页面路由：`#/creator-income`、`#/creator-workboard`

## 1. 产品概述

### 1.1 产品目标

为创作者运营、BD 和财务协作人员提供两类工作视图：

1. **作者跟进**：按账期查看创作者收入、账号合作状态、风险状态和 BD 责任归属，并支持进入单作者诊断。
2. **作者作品看板**：分别按作者和作品查看内容生产、免费吸引力、付费转化、付费观看及退费表现，用于发现高潜作者/作品和定位经营问题。

### 1.2 页面关系

| 页面 | 路由 | 核心对象 | 主要动作 |
| --- | --- | --- | --- |
| 作者跟进 | `#/creator-income` | 创作者账号、账期收入、BD 责任人 | 筛选、查看收入汇总、编辑 BD、解绑实名、进入创作者诊断、导出收入明细 |
| 作者作品看板 | `#/creator-workboard` | 作者、作品及内容经营指标 | 作者/作品视图切换、关键词筛选、查看阈值提醒、导出看板明细 |

### 1.3 角色

| 角色 | 使用目的 |
| --- | --- |
| 创作者运营 | 跟进作者合作状态、风险和内容增长 |
| BD | 维护责任归属，结合收入和内容表现推进作者合作 |
| 财务/结算人员 | 查看账期收入、签约/绑卡状态和可结算条件 |

## 2. 公共数据和展示约定

### 2.1 ID 与数据时间

| 字段 | 定义 |
| --- | --- |
| `authorId` | 创作者唯一 ID，例如 `AUTH-10018`；不得使用作者昵称作为唯一键 |
| `collectionId` | 作品/合集唯一 ID；用于收入明细和作品详情关联 |
| `month` | 收入所属账期，格式 `YYYY-MM`；页面按自然月选择账期 |
| `date` | 收入发生日期；展示格式 `MM-DD`，数据层保留完整日期 |
| 数据刷新时间 | 页面右上角展示最近一次数据更新时间；Demo 为静态时间，生产环境应来自接口返回 |

### 2.2 数值格式

| 类型 | 展示规则 |
| --- | --- |
| 金额 | 人民币，保留 2 位小数或按页面金额格式化为 `¥12,600`；导出保留数值或带币种字符串需统一 |
| 百分比 | 保留 1 位小数，例如 `58.2%`；阈值判断使用原始数值，不使用四舍五入后的展示值 |
| 播放量/曝光量 | 整数，页面千分位展示，例如 `286,400` |
| 增长值 | 正数带 `+`，负数带 `-`；无数据展示 `--`，零值展示 `0` |
| 状态 | 页面使用带背景色的标签；导出使用状态文本，不导出颜色 |

### 2.3 空值和权限

- 无数据时显示 `--`，不可用字段不得伪装成 0。
- 没有权限的字段显示 `无权限`，不参与筛选和汇总。
- 关键词搜索不区分大小写，支持部分匹配。
- 所有筛选条件同时生效，清空筛选后恢复当前页面默认状态。

## 3. 页面一：作者跟进

### 3.1 页面定位

页面标题为“创作者收入”，导航名称为“作者跟进”。页面以创作者为行聚合收入，同时展示合同签约、银行卡、关联企业、安全风险和 BD 责任人。创作者昵称可进入“创作者诊断”。

### 3.2 筛选区

| UI 字段 | 数据字段 | 类型 | 口径/行为 | 默认值 |
| --- | --- | --- | --- | --- |
| 搜索创作者 | `incomeAuthor` | string | 匹配 `author`、`authorId`、`enterprise`，包含匹配，不区分大小写 | 空 |
| 收入周期 | `incomePeriod` | enum | `全部周期`；`近 7 天`按选定账期内日期日号 `>=21`；`近 30 天`为选定账期全量数据 | 全部周期 |
| 合同签约状态 | `incomeContract` | enum | `done`=已签约，`pending`=待签约；为空表示全部 | 全部签约状态 |
| 绑卡状态 | `incomeBank` | enum | `done`=已绑卡，`pending`=待绑卡；为空表示全部 | 全部绑卡状态 |
| BD 责任人 | `incomeBdOwner` | enum | 空=全部；`unassigned`=未分配；其他值按 `bdOwnerId` 精确匹配 | 全部 BD 责任人 |
| 账期选择 | `incomeMonth` | `YYYY-MM` | 按收入记录的 `month` 精确筛选；切换账期后卡片、表格和导出均刷新 | `2026-10` |
| 清空筛选 | — | action | 清除筛选并恢复页面默认值 | — |
| 导出明细 | — | action | 导出当前收入明细 CSV；生产环境应携带全部筛选条件 | — |

### 3.3 汇总卡片和图表

#### 3.3.3 账号状态摘要

页面当前将签约率和绑卡率合并放在收入贡献卡片底部：

| 字段 | 公式 | 展示 |
| --- | --- | --- |
| 签约率 | `contract=done` 的创作者数 / 筛选后创作者总数 × 100% | 四舍五入为整数百分比 |

### 3.6 BD 责任人编辑

1. 点击责任人姓名下方的小铅笔图标，进入当前行编辑态。
2. 输入工号或姓名，实时过滤责任人候选。
3. 点击候选人员后展示选中态。
4. 点击“确认”回填 `bdOwnerId`、`bdOwnerName`；点击“取消”恢复原值。
5. 未选择人员时“确认”按钮置灰。
6. 保存后当前表格、BD 筛选选项和后续诊断入口立即使用新责任人。

待签约作者的“复制合同链接”按钮按作者 ID 生成合同地址。点击后复制链接到剪贴板，并通过 Toast 告知“合同链接已复制”；如果浏览器不支持剪贴板，则降级展示可复制的合同地址。

### 3.7 作者诊断跳转

点击作者昵称进入“创作者诊断”页，传递 `authorId`。诊断页至少读取：作者账号状态、风险标签、当前收入明细，以及来自作者作品看板的作者层级、有效作品、有效观看、30 日留存、潜力状态。

### 3.8 作者跟进导出字段

收入明细导出字段如下，字段顺序固定：

| CSV 表头 | 数据字段 | 口径 |
| --- | --- | --- |
| 日期 | `date` | 收入发生日期 |
| 创作者 | `author` | 作者昵称 |
| 合集 | `collection` | 收入归属合集 |
| 订单数 | `orders` | 订单数量 |
| 流水 | `gross` | 用户侧收入流水 |
| 创作者分成 | `share` | 创作者应得分成 |
| 平台服务费 | `fee` | 平台服务费；如未单独存储，可按 `gross-share` 计算 |
| 状态 | `status` | 结算状态原文 |

## 4. 页面二：作者作品看板

### 4.1 页面定位

页面标题为“作者作品看板”，提供“作者”和“作品”两个相互独立的视图。作者视图字段调整不得影响作品视图字段。

### 4.2 公共操作区

| UI 字段 | 数据字段 | 行为 |
| --- | --- | --- |
| 搜索框（作者视图） | `workboardKeyword` | 匹配 `author`、`authorId` |
| 搜索框（作品视图） | `workboardKeyword` | 匹配 `title`、`author` |
| 作者 Tab | `workboardView=authors` | 显示作者指标表 |
| 作品 Tab | `workboardView=works` | 显示作品指标表 |
| 清空筛选 | — | 清除关键词，保留当前作者/作品 Tab |
| 导出明细 | — | 按当前 Tab 和关键词导出对应字段 |

### 4.3 作者视图字段

作者表字段顺序固定如下。作者列包含作者昵称、作者 ID 和可选的“加广”标签；潜力层级只显示带背景色的标签，不重复展示文字。

| 2 | 潜力层级 | `potential`、`status` | enum | 彩色标签展示作者潜力层级；不额外显示 `level` 重复文本 |
| 3 | 剧集数 | `episodeStructure` 或 `works` | string | 统一展示为“x个y集结构”；例如“2个18集结构”“1个12集结构” |
| 4 | 更新频次 | `cadence` | string | 作者平均更新频次，例如 `4.5 集 / 月` |
| 5 | 免费视频数 | `freeVideos` | integer | 作者当前统计范围内可免费观看的视频数量 |
| 6 | 免费平均播放量 | `views` | integer | 免费视频播放量平均值；页面千分位展示 |

| 9 | 7日粉丝增长 | `followers7d` | integer | 最近 7 日粉丝净增长；正数带 `+` |

| 11 | 付费完播率 | `paidCompletion80` | percentage | 付费视频观看达到 80% 的比例 |
| 12 | 作者收入 | `income` | money | 当前统计周期作者收入 |
| 13 | 激励成本 | `cost` | money | 平台为作者或内容投入的激励成本 |
| 14 | 30日留存 | `retention` | percentage | 首次消费/观看用户在 30 日后仍回访或继续观看的比例 |

### 4.6 已删除字段

以下字段不应重新出现在作品视图的表头、数据行或导出文件中：

- `completion30`：30% 完播率。
- 免费累计播放量/累计播放量列。
- 点赞率、评论率、收藏率、弹幕率四个拆分列；统一使用“互动率”。

### 4.7 阈值提醒规则

阈值比较使用原始百分比数值，严格按下表条件判断：

| 指标 | 条件 | 颜色 | 含义 |
| --- | --- | --- | --- |
| 2s 跳出率 | `> 50%` | 红色 | 免费内容开场留存风险 |
| 退费率 | `> 5%` | 红色 | 付费内容或预期管理存在风险 |
| 80% 完播率 | `> 70%` | 绿色 | 深度观看表现较好 |
| 连播率 | `> 60%` | 绿色 | 内容连续消费表现较好 |
| 购买点击率 | `> 10%` | 绿色 | 付费转化意愿较强 |

等于阈值时不高亮。红色和绿色只作用于对应单元格，不改变整行颜色；导出文件保留原始数值，不附加颜色信息。

## 6. 交互和异常处理

| 场景 | 处理 |
| --- | --- |
| 搜索无结果 | 保留表头，展示“暂无匹配作者/作品”和调整关键词提示 |
| 账期无收入但有账号 | 账号仍展示，收入汇总显示 0；不可隐藏账号状态 |
| BD 责任人候选为空 | 显示无匹配结果，确认按钮保持禁用 |
| 解绑实名 | 必须二次确认；成功后刷新状态，不删除收入、作品和历史数据 |
| 导出 | 导出当前视图字段和当前筛选结果；文件名分别为 `creator-income.csv`、`creator-workboard.csv` |
| 指标缺失 | 展示 `--`；缺失值不参与阈值高亮 |
| 阈值刚好相等 | 不触发颜色提醒，例如 `50%` 的 2s 跳出率不标红 |
| 横向字段较多 | 作品列和潜力状态列左侧吸附，其余字段可横向滚动 |
