# 天天学 Creator Studio Demo

这是面向内部评审的移动端 H5 创作者中心 Demo，聚焦作者登录注册、版权协议确认、作品管理提示、数据中心、实名认证、银行卡绑定和提现流程。

## 运行

在当前目录启动静态服务：

```bash
python3 -m http.server 4173 --directory /Users/tal/Desktop/天天学/creator-platform-demo
```

浏览器访问 <http://localhost:4173>。建议使用手机宽度或浏览器开发者工具的移动设备模式查看。

## 推荐演示路径

1. 注册页填写昵称、手机号和验证码 `123456`。
2. 勾选并打开《创作者版权协议》，确认后完成注册。
3. 注册/登录成功后，未认证账号会自动进入账号设置并弹出实名认证引导；认证通过后自动进入数据中心。
4. 已认证账号再次登录会直接进入数据中心。
5. 底部切换“数据中心”，体验昨日、7 天、30 天、自定义日期和播放/分成趋势。
6. 进入“账号设置”修改昵称、手机号，完成实名认证和银行卡绑定。
7. 从收益卡片进入提现，提交金额后模拟审核通过，再模拟支付成功并对账。

## 异常路径

- 实名认证页可以模拟证件无效、未成年人和认证通过。
- 提现页会校验最低提现金额、可提现余额和银行卡绑定状态。
- 账号设置支持昵称、手机号、实名认证和银行卡流程。
- 数据中心复刻参考 H5 页面：排名、数据指标、趋势图和单作品数据。
- 退出登录后重新回到登录/注册门禁页。

## 说明

Demo 使用本地预置数据，不连接真实身份认证、支付渠道、税务或财务系统。页面中的身份证和支付状态仅用于演示产品交互，不应填写真实敏感信息。
