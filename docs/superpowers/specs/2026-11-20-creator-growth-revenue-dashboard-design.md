# 创作者成长收益看板设计

## 目标

将创作者运营规划 H5 中的“成本与收益看板”升级为可点击的看板入口，并新增独立的成长收益二级页面，用静态演示数据展示平台、作者和作品三个层面的经营状态，重点支持识别作者与作品的潜力状态。

## 范围

- 修改：`创作者运营规划-H5.html`
- 新增：`创作者运营成长收益看板-H5.html`
- 后续同步修改项目根目录内对应 H5 文件，并验证二级页面链接
- 不接入真实 API，不修改现有平台阶段、激励体系和角色分工内容
- 不修改当前 `contest/index.html` 的既有未提交改动

## 页面关系

主页面的“成本与收益看板”保留四类指标卡，但增加“查看成长收益看板”入口。点击后打开独立的成长收益看板页面；二级页面提供返回主规划页的入口，并保留静态数据展示能力，便于后续替换为真实数据接口。

## 二级页面结构

### 1. 顶部状态区

展示页面标题、数据更新时间、周期筛选和返回规划入口。周期提供近 7 日、近 30 日和季度三个演示选项，切换时更新页面的状态文案与表格数据。

### 2. 整体经营总览

使用指标卡展示：有效作者、有效作品、稳定产出率、平台净收入、激励 ROI 和生态健康度。指标卡同时给出环比变化或状态标签，形成平台整体经营结果的快速判断。

### 3. 作者维度

作者表格至少包含：作者名称、层级、有效作品数、更新频次、平均有效观看、平均完播率、付费转化率、创作者收入、平台贡献收入、单作者成本、30 日留存和潜力状态。

作者潜力状态按“高潜作者、成长作者、稳定作者、观察对象”展示。判断逻辑综合考虑稳定产出、内容质量、商业转化、留存和投入产出，不使用单一播放量直接判定。

### 4. 作品维度

作品表格至少包含：作品名称、所属作者、内容类型、集数、有效观看、完播率、互动率、付费转化率、收入、退款率、近 7 日增长、流量成本和潜力状态。

作品潜力状态按“高潜作品、成长作品、稳定作品、待优化”展示。判断逻辑综合考虑消费质量、互动、转化、增长速度和退款风险。

### 5. 判断说明

页面底部说明作者和作品潜力状态为运营识别标签，不直接等同于奖励资格或最终结算口径。演示数据应明确标记为 Demo 数据，避免被误解为真实经营结果。

## 交互设计

- 主 H5 的看板入口整卡可点击，并提供明确的箭头和“查看成长收益看板”文字。
- 二级页面通过作者 / 作品 Tab 切换数据表。
- 周期筛选切换总览指标、趋势摘要和对应表格数据。
- 表格中的潜力状态使用颜色区分，但同时保留文字，保证移动端可读性。
- 页面在窄屏下允许表格横向滚动，不压缩关键指标到不可读状态。

## 数据结构与后续接口边界

演示数据按 `overview`、`authors`、`works` 和 `periods` 四个对象组织。页面渲染逻辑只依赖这些字段，后续接 API 时可以替换数据源，不需要重写展示结构。作者和作品必须使用独立数据集合，避免把作者累计数据误用于单作品判断。

## 验证

- 主 H5 的入口存在，链接能打开成长收益二级页面。
- 二级页面可在总览、作者、作品三个视图之间切换。
- 周期切换会更新页面数据和状态文案。
- 作者与作品表格都能展示必要字段和潜力状态。
- 本地静态文件路径有效，关键 HTML 结构和脚本无明显错误。
- Git diff 不覆盖 `contest/index.html` 的已有未提交修改。
